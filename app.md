# Push-Mitteilungen im Browser

Die Website nutzt **keine installierte App** — alles läuft im **normalen Browser** (Chrome, Safari, Firefox).

So aktivierst du Vereins-Pushs:

## Schritt 1 — Einloggen

1. **mtb-werdohl.de** im Browser öffnen (Link aus WhatsApp ist in Ordnung)
2. Oben **Mitglieder** → Vereins-E-Mail → **Login-Link senden**
3. Link aus der E-Mail öffnen → du landest auf **Mein Profil**

## Schritt 2 — Push bestellen

1. Auf **Profil** nach unten zu **Push-Mitteilungen** scrollen
2. **Push bestellen** tippen
3. Benachrichtigungen im Browser-Dialog **erlauben**

Vergangene Mitteilungen: **[Mitteilungen](/mitteilungen/)**

## Hinweise

| Thema | Empfehlung |
|--------|------------|
| **WhatsApp-Links** | Immer im Browser öffnen — gleiche Adresse wie oben |
| **Android** | Chrome empfohlen |
| **iPhone** | Safari; Web-Push wird vom Gerät/Browser unterstützt oder nicht — bei Problemen reicht die Anzeige auf der Website ([Mitteilungen](/mitteilungen/)) |
| **Abmelden** | Profil → Push abbestellen |
